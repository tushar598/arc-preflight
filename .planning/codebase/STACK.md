# Tech Stack

## Core
- **Framework**: Next.js 16.3.5 (App Router)
- **Language**: TypeScript
- **UI Library**: React 19.2.8
- **Styling**: Tailwind CSS v4, PostCSS
- **Monorepo / Workspaces**: npm workspaces (app + `arc-preflight` SDK)

## Web3 & Crypto
- **Wallet Connection**: RainbowKit v2.2.11
- **Ethereum Interactions**: Wagmi v3.7.7, Viem v2.56.8
- **Custom SDK**: `arc-preflight` (Local workspace package for OFAC sanctions checks and native simulations)

## UI & Animation
- **Animation**: GSAP (GreenSock Animation Platform) + ScrollTrigger
- **Smooth Scrolling**: Lenis
- **Icons**: Lucide React
- **Fonts**: IBM Plex Sans, IBM Plex Mono (next/font/google)

## Build & Dev
- **Development**: Next dev (Turbopack)
- **SDK Build**: tsup
- **TypeScript**: tsc
- **Linting**: ESLint
